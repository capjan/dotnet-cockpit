## See clearly. Change deliberately.

- **One environment:** inventory reflects the `dotnet` host Cockpit resolves, with version-specific installation paths.
- **Useful context:** release metadata adds lifecycle dates, support status and available patches. When it is unavailable, support status stays unknown.
- **You stay in control:** changes require confirmation. Global tools and local declarations remain distinct, and an inherited parent manifest cannot be removed.

Searching, sorting and core actions also work with JavaScript disabled. [Explore the workspace →](Features.md)
